AI and development tools — Tech watch sheet

Sheet opened on November 24, 2026 · facts checked on that date

Why this topic

AI assistants no longer just answer questions: coding agents read a project, run commands and connect to external tools. For a developer, this changes the way we work, and it creates new security risks to keep under control.

Key facts

  • MCP (Model Context Protocol): an open standard launched by Anthropic in November 2024 to connect an AI assistant to tools and data (files, databases, APIs). On December 9, 2025, it was handed over to the Agentic AI Foundation, a Linux Foundation project co-founded by Anthropic, Block and OpenAI. The Linux Foundation counts more than 10,000 published MCP servers; the protocol is used by Claude, ChatGPT, Gemini, Microsoft Copilot, Cursor and VS Code.
  • Agent Skills: an open format published by Anthropic on December 18, 2025 (specification at agentskills.io). A Skill is a folder of instructions and scripts that the agent loads only when a task calls for it. The format was adopted by other platforms, then handed over to the same foundation as MCP.
  • Security: in the OWASP Top 10 for generative AI applications (2025 edition), prompt injection remains risk #1 (LLM01). Instructions hidden in content read by the assistant (web page, file, email) can hijack it. Recommended countermeasures: limit the agent's permissions, keep external content separate from instructions, and have a human approve sensitive actions.

Link with my projects

  • NEXUS, my desktop AI assistant (Tauri): it calls tools on my computer, which raises exactly the permission and control questions described by OWASP.
